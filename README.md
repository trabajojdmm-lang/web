# Portafolio web de Jairo

Sitio estático personal hecho con HTML, CSS y JavaScript, sin dependencias de compilación.

## Vista previa local

Desde la raíz del proyecto:

```bash
python -m http.server 8000
```

Abre `http://localhost:8000`.

## Publicación

El workflow de GitHub Actions en `.github/workflows/pages.yml` publica el sitio en GitHub Pages cuando hay cambios en `main`.
